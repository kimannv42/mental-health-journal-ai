# AI-Powered Mental Health Journal & ChatBot

A full-stack web application designed to support mental well-being through mood tracking, AI-assisted journaling, emotion detection, and conversational support.

## Features

- 😊 Mood Selection and Tracking
- 📝 AI-Assisted Journaling
- 🤖 Conversational AI ChatBot
- 🎥 Webcam-Based Emotion Detection
- 💾 Journal Entry Storage using MongoDB
- 🗑️ Delete Journal Entries
- 📱 Responsive User Interface

## Technologies Used

### Frontend
- Next.js
- React
- TypeScript

### Backend
- Next.js API Routes
- Node.js

### Database
- MongoDB Atlas

### AI & Machine Learning
- Groq API
- LLaMA 3.1
- face-api.js

## System Workflow

1. User selects a mood.
2. User writes a journal entry.
3. Emotion and supportive response are generated.
4. Entry is stored in MongoDB.
5. User can view or delete past entries.
6. User can chat with the AI assistant.
7. Webcam emotion detection can automatically suggest moods.
